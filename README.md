# 🚀 AI Career Copilot

An AI-powered career guidance platform that helps users analyze resumes, improve ATS scores, prepare for interviews, generate cover letters, and receive personalized career roadmaps using Google's Gemini AI.

## 📌 Features

- 📄 AI Resume Analysis
  - Upload PDF resumes
  - ATS score evaluation
  - Resume strengths & weaknesses
  - Recruiter-style feedback

- 🎯 Career Guidance
  - Personalized career recommendations
  - Skill gap analysis
  - Learning roadmap generation
  - Recommended technologies and certifications

- 💼 Interview Preparation
  - AI-generated interview questions
  - Topic-wise preparation roadmap
  - Technical interview guidance

- ✍️ AI Cover Letter Generator
  - Generates professional cover letters
  - Tailored to job roles

- 📊 Visual Analytics
  - ATS Score Gauge
  - Score Breakdown Charts
  - Skill Matrix
  - Career Recommendation Cards

- 📜 Analysis History
  - View previous resume analyses
  - Track improvements over time

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/your-username/ai-career-copilot.git
```

## 2. Navigate to the project

```bash
cd ai-career-copilot
```

## 3. Install dependencies

```bash
npm install
```

or

```bash
bun install
```

---

# 🔑 Environment Variables

Create a `.env` file in the root directory.

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

---

# ▶️ Run the Application

Start the development server:

```bash
npm run dev
```

or

```bash
bun run dev
```

The application will be available at:

```
http://localhost:3000
```

or the port displayed in your terminal.
